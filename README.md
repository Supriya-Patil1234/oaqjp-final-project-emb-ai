# Emotion Detector Application

An AI-based web application leveraging IBM Watson NLP and Flask to analyze emotions from text inputs.

## Features
- Emotion analysis returning scores for anger, disgust, fear, joy, and sadness.
- Identification of dominant emotion.
- Robust error handling for empty/invalid inputs (HTTP 400).
- Flask web interface and REST API endpoint.
- Comprehensive unit testing suite.
